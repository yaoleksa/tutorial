The easiest way to make a React application

To start using a React framework within your project, first of all, you need to include all required packages, add an importmap and set a file with your main logic type text/babel and data-type module. In the code snippet below, you can see an example of how to implement this 


                <!doctype html>
                <html dir="ltr" lang="uk">
                <head>
                    <meta charset="utf-8">
                    <title>Tic-Tac-Toe </title>
                    <style> </style>
                    <script src="https://unpkg.com/@babel/standalone/babel.min.js"> </script>
                    <script src="https://ga.jspm.io/npm:es-module-shims@1.7.0/dist/es-module-shims.js"> </script>
                    <script type="importmap">
                        {
                            "imports": {
                                "react": "https://esm.sh/react?dev",
                                "react-dom/client": "https://esm.sh/react-dom/client?dev"
                            }
                        }
                    </script>
                    <script type="text/babel" data-type="module" src="app.js"> </script>
                </head>
                <body>
                    <div id="root"> </div>
                </body>
                </html>

Important notice! This application will be available only via an HTTP server. You can run the server on your own or use the VS Code extension Live Server. To do it with the Live Server extension, just open the folder with your script, click the right mouse button on your script file, and then click Open with Live Server. Extension is running your application on the http://127.0.0.1:5500/ address. One more important notice in terms of the Live Server extension. You have to run your .html file, not .js. If you want to stop the server listening, just click on the Port: 5500 text on the bottom right.
